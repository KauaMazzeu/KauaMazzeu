### 🎯 Áreas de Foco & Atuação

- 🔴 **Offensive Security & Red Team:**
  - Avaliação de segurança em aplicações web (OWASP Top 10, SQLi, XXE, quebra de lógica/autenticação).

- 🔵 **Defensive Security & Blue Team:**

  - Endurecimento de sistemas (Hardening), boas práticas de configuração e mitigação de vulnerabilidades.
  - Análise de comportamento de ataques para criação de regras de detecção e contenção.

- 🔍 **Digital Forensics & Incident Response (DFIR):**
  - Coleta, preservação e análise de evidências digitais (cadeia de custódia).
  - Análise de logs de sistemas operacionais, serviços web e bases de dados para rastreamento de rastros de intrusão.
  - Perícia de artefatos de rede e correlação de eventos pós-incidente.
